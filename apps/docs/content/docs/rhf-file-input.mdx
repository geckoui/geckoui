# RHFFileInput

[FileInput](/docs/file-input) wired to React Hook Form.

## Installation

```tsx
import { RHFFileInput } from '@geckoui/geckoui';
```

## Basic Usage

<Preview>
  <BasicRHFFileInputExample />
</Preview>

```tsx
import { FormProvider, useForm } from 'react-hook-form';
import { RHFFileInput, type PickedFile } from '@geckoui/geckoui';

function ApplicationForm() {
  const methods = useForm<{ cv: PickedFile | null }>({ defaultValues: { cv: null } });

  return (
    <FormProvider {...methods}>
      <form onSubmit={methods.handleSubmit(save)}>
        <RHFFileInput name="cv" accept=".pdf,.docx" />
      </form>
    </FormProvider>
  );
}
```

The field holds a `PickedFile` when single and a `PickedFile[]` when `multiple`. Files are real `File` objects, so they go straight into a `FormData`.

## Props API

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `name` | `string` | required | The field path |
| `control` | `Control` | - | Taken from `FormProvider` when left out |
| `rules` | `RegisterOptions` | - | Validation rules |
| `onChange` | `(value) => void` | - | Called alongside the form update |
| ...rest | `FileInputProps` | - | Everything [FileInput](/docs/file-input) takes, except `value` and `hasError` |

`hasError` is set for you from the field's own error, so it is not yours to pass.

## Requiring one

<Preview>
  <RHFFileInputRequiredExample />
</Preview>

```tsx
<RHFFileInput name="avatar" accept="image/*" rules={{ required: 'Pick a file' }} />
<RHFError name="avatar" />
```

A single field holds `null` until something is picked, so `required` catches it.

## Several files

<Preview>
  <RHFFileInputMultipleExample />
</Preview>

```tsx
<RHFFileInput
  name="docs"
  multiple
  append
  unique
  max={3}
  rules={{ validate: (files) => files.length > 0 || 'Add at least one' }}
/>
<RHFError name="docs" />
```

A multiple field holds `[]` rather than `null`, and `required` does not catch an empty array — use `validate`, as above.

`append`, `unique` and `max` are only accepted alongside `multiple`; TypeScript rejects them otherwise.

## Uploading

```tsx
const onSubmit = async ({ docs }: { docs: PickedFile[] }) => {
  const body = new FormData();

  docs.forEach((file) => body.append('files', file, file.path || file.name));

  await fetch('/upload', { method: 'POST', body });
};
```

`path` carries the folder a dropped file came from, so a directory upload can be rebuilt on the server. It is `""` for a file picked on its own.
