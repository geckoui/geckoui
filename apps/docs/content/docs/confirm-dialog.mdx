# ConfirmDialog

ConfirmDialog is a flexible confirmation modal component that prompts users for action validation. Built on top of the Dialog component, it provides a standardized interface for displaying confirmation prompts with customizable content, buttons, and behavior.

## Setup

Requires [`<GeckoUIProvider>`](/docs/gecko-ui-provider) to wrap your app.

```tsx
import { ConfirmDialog } from '@geckoui/geckoui';
```

## Basic Usage

<Preview>
  <BasicConfirmDialogExample />
</Preview>

```tsx
ConfirmDialog.show({
  title: "Confirm Action",
  content: "Are you sure you want to proceed?",
  onConfirm: () => {
    console.log('Confirmed');
  }
});
```

## API Reference

### ConfirmDialog.show(options)

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `title` | `string` | — | Dialog title |
| `content` | `ReactNode \| FC<{dismiss}>` | — | Dialog content |
| `confirmButtonLabel` | `string` | `'Ok'` | Confirm button text |
| `cancelButtonLabel` | `string` | `'Cancel'` | Cancel button text |
| `onConfirm` | `(args) => void \| Promise<void>` | — | Confirm callback |
| `onCancel` | `(args) => void \| Promise<void>` | — | Cancel callback |
| `className` | `string` | — | CSS class for dialog |
| `titleClassName` | `string` | — | CSS class for title |
| `contentClassName` | `string` | — | CSS class for content |
| `dismissOnEscape` | `boolean` | `true` | Close on Escape key |
| `dismissOnOutsideClick` | `boolean` | `true` | Close on outside click |

**Returns:** `string` — the overlay id (forwarded from `Dialog.show`).

### Callback Arguments

Both `onConfirm` and `onCancel` receive an object with:

| Argument | Type | Description |
|----------|------|-------------|
| `preventDefault` | `() => void` | Prevent auto-close after callback |
| `dismiss` | `() => void` | Manually close dialog |

### ConfirmDialog.dismiss(id?)

Programmatically closes the confirm dialog. Pass the `id` returned by `show()` to close a specific dialog, or call with no argument to close the topmost overlay.

## Examples

### Delete Confirmation (Async)

<Preview>
  <DeleteConfirmDialogExample />
</Preview>

```tsx
function DeleteButton({ itemId }) {
  const handleDelete = () => {
    ConfirmDialog.show({
      title: "Delete Item",
      content: "Are you sure you want to delete this item? This action cannot be undone.",
      confirmButtonLabel: "Delete",
      cancelButtonLabel: "Keep",
      onConfirm: async () => {
        await deleteItem(itemId);
        toast.success("Item deleted");
      }
    });
  };

  return <Button onClick={handleDelete}>Delete</Button>;
}
```

### Rich Content with Custom Component

<Preview>
  <RichContentConfirmDialogExample />

```tsx
ConfirmDialog.show({
  title: "Transfer Ownership",
  content: ({ dismiss }) => (
    <div className="space-y-4">
      <p>Transfer project ownership to:</p>
      <UserSelector onSelect={setSelectedUser} />
      <Button variant="link" onClick={dismiss}>Cancel transfer</Button>
    </div>
  ),
  confirmButtonLabel: "Transfer Now",
  onConfirm: () => {
    performTransfer();
  }
});
```

### Programmatic Dismissal

```tsx
const id = ConfirmDialog.show({
  title: "Processing",
  content: "Please wait while we process your request..."
});

// Close from anywhere
ConfirmDialog.dismiss(id);
```

## Behavior

- If `onConfirm` or `onCancel` is declared `async`, the respective button shows a loading state until the promise resolves.
- The check is on the function itself, not on what it returns. A function that returns a promise without being declared `async` gets no loading state:

  ```tsx
  // loading state
  onConfirm: async () => { await deleteUser(id); }

  // no loading state, the dialog closes straight away
  onConfirm: () => deleteUser(id)
  ```

  Use this when you deliberately want the dialog to close without waiting.
- After the callback resolves, the dialog closes automatically unless `preventDefault()` was called.
- Pressing Enter confirms (when no focusable element is focused), and only when the confirm dialog is the topmost overlay. Stacked dialogs below it ignore Enter.
