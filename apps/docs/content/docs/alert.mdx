# Alert

An alert component for displaying important messages with different severity levels. Supports multiple colours (error, success, warning, info, default), optional descriptions, custom icons, and dismissal functionality.

## Installation

```tsx
import { Alert } from '@geckoui/geckoui';
```

## Basic Usage

<Preview>
  <Alert title="This is an alert message" />
</Preview>

```tsx
<Alert title="This is an alert message" />
```

## Props API

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `title` | `ReactNode \| FC` | - | Main message (required) |
| `color` | `'error' \| 'success' \| 'warning' \| 'info' \| 'default'` | `'default'` | What the alert means. Named `color` to match `Button` and `Badge` |
| `description` | `ReactNode \| FC` | - | Additional detailed text |
| `condensed` | `boolean` | `false` | Reduced vertical padding |
| `onRemove` | `() => void` | - | Callback for dismiss button |
| `icon` | `ReactNode \| FC` | - | Custom icon element |
| `iconClassName` | `string` | - | CSS class for default icon |
| `className` | `string` | - | CSS class for container |

### Dismissible Alert

<Preview>
  <DismissibleAlertExample />
</Preview>

```tsx
function DismissibleAlert() {
  const [show, setShow] = useState(true);

  if (!show) {
    return (
      <Button size="sm" onClick={() => setShow(true)}>
        Show Alert Again
      </Button>
    );
  }

  return (
    <Alert
      color="warning"
      title="Storage almost full"
      description="You're using 95% of your storage. Upgrade your plan to avoid interruptions."
      onRemove={() => setShow(false)}
    />
  );
}
```

## Behavior

### Dismiss Button

When `onRemove` callback is provided, a close button appears in the top-right corner. Clicking it triggers the callback:

```tsx
<Alert
  title="Dismissible alert"
  onRemove={() => {
    console.log('Alert dismissed');
    // Hide alert or perform cleanup
  }}
/>
```

### Condensed Mode

The `condensed` prop reduces vertical padding for a more compact appearance, ideal for inline notifications:

```tsx
<Alert condensed title="Compact notification" />
```

## Module Augmentation

The Alert component supports TypeScript module augmentation, allowing you to add custom colours with full type safety.

### Live Example

A custom `critical` colour created using module augmentation:

<Preview>

### Step 1: TypeScript Declaration

Create a declaration file (e.g., `gecko.d.ts`) in your project:

```typescript
import "@geckoui/geckoui";

declare module "@geckoui/geckoui" {
  interface AlertColorMap {
    critical: unknown;
  }
}
```

## Styling

The component uses `data-*` attributes for state and colour styling:

- `data-color` — Colour (error, warning, info, success, default)
- `data-condensed` — Present when condensed mode is enabled

BEM class names for structural elements:

- `GeckoUIAlert` — Main container
- `GeckoUIAlert__body` — Content wrapper
- `GeckoUIAlert__icon` — Icon element
- `GeckoUIAlert__title` — Title text
- `GeckoUIAlert__description` — Description text
- `GeckoUIAlert__remove-button` — Dismiss button
- `GeckoUIAlert__remove-button__icon` — Dismiss button icon

## Styling with CSS

Alert reads the shared semantic tokens, so changing one updates every component that reports
status, Toast included:

```css
:root {
  --color-error: oklch(0.6 0.22 25);
  --color-warning: oklch(0.7 0.16 60);
  --color-info: oklch(0.62 0.19 260);
  --color-success: oklch(0.65 0.18 150);
}
```

The alert itself exposes its own variables:

| Variable | Default | Applies to |
|----------|---------|------------|
| `--gecko-alert-bg` | `--color-surface-primary` | Background |
| `--gecko-alert-border` | `--color-border-primary` | Border colour |
| `--gecko-alert-accent` | per colour | Title text and icon |
| `--gecko-alert-radius` | `0.5rem` | Corner radius |

Scope a variable to one colour to restyle only that one:

```css
.GeckoUIAlert[data-color="error"] {
  --gecko-alert-bg: var(--color-error);
  --gecko-alert-accent: white;
}
```
